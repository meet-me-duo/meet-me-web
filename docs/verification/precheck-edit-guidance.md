# NEEDS_EDIT 수정 안내 호환 처리 — 제안 계약 준비

2026-10-28 부모 작업에서 제안한 `check.edit_guidance: nullable string`의 UI 호환 경로다. 실제 생성 서버 명세는 아직 전달 전이며 이 기록은 계약 확정이나 운영 반영을 뜻하지 않는다. 기존 PR49 계정/방 정리와 별도 브랜치로 준비했다.

NEEDS_EDIT이며 비어 있지 않은 문자열인 경우에만 서버 안내를 일반 React 텍스트로 표시한다. HTML/Markdown/링크를 해석하거나 오류코드·모델 사유를 추정하지 않는다. 기존 A/B question과 분리한다. 필드 없음/null/빈값/잘못된 타입이면 기존 원인 비단정 안내를 유지한다. 마감·완료·수정/미저장 상태의 기존 표시 제한과 요청/계정 경계는 유지한다. 원문·이전 확정 조건을 바꾸지 않으며 자동 제출하지 않는다.

단위9/9, 제출 전 확인 E2E34/34(desktop/mobile ×320/390/1440px), lint/type/build 통과. 구버전 필드 누락의 fallback, 일반 텍스트 escaping, 줄바꿈/가로 넘침, 원문 보존과 명시적 수정, 취소/닫힘 후 숨김을 검사했다. 독립 검토와 관련 단위23/23도 통과했다. 실제 API·계정·방 동작은 실행하지 않았다.
